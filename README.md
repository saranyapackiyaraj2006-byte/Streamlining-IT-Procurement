Standard Laptop IT Procurement Flow
Overview
The Standard Laptop Task Flow automates the creation and assignment of catalog tasks for standard laptop requests.

Once a request meets the configured approval criteria, the flow automatically creates a catalog task under the related Requested Item (RITM). The task is then assigned to the Hardware Assignment Group for laptop preparation and configuration.

Purpose
This automation streamlines the IT procurement process by:

Reducing manual task creation
Ensuring approved laptop requests are processed efficiently
Assigning configuration activities to the appropriate support team
Improving visibility and tracking of laptop provisioning tasks
Process Flow
A user submits a Standard Laptop request.
The request goes through the configured approval process.
Once the approval condition is met, the flow is triggered.
A catalog task is created under the associated Requested Item.
The task is assigned to the Hardware Assignment Group.
The Hardware team configures and prepares the laptop for delivery.

Prerequisites
Before activating the flow, ensure that:

The Standard Laptop catalog item is available.
The approval process is properly configured.
The Hardware assignment group exists and is active.
The flow has permission to create catalog tasks.
The Requested Item relationship is correctly configured.
Expected Outcome
For every approved Standard Laptop request, the system creates a corresponding catalog task under the related Requested Item and assigns it to the Hardware team for further processing.
